# 拾音 · 拾链主题版 2.2.1

本目录是播放器的独立主题版，位于 **main 分支的 `zt/` 目录**。与普通版共用TGDrive音频模块，保留拾音主题布局。

## 部署

在仓库根目录运行 `npm ci && npm run build`，将 `dist/zt-worker.js` 的全部内容替换到 Cloudflare Worker，继续保留：

- R2 绑定：`MUSIC_BUCKET`
- 管理令牌：`AUTH_TOKEN`（建议设置，不在代码里填写）

使用原有R2播放无需数据库；启用TGDrive来源时添加 `MUSIC_DB` D1、`TGDRIVE_URL` 和音频专用 `TGDRIVE_TOKEN`。已有自定义站名、副标题、Logo、R2歌曲封面和背景继续使用。

管理员登录后可点击「从 TGDrive 添加歌曲」，搜索和勾选音频，设置自定义歌名、专辑和海报。配置详情见 [TGDrive接入](../docs/tgdrive.md)。

## 主题

- ShareDrop 同款深绿底色 `#0b211e`、卡片 `#142d28`、青柠强调 `#d1f879`。
- 音乐版文案：**好音乐，慢慢「听」见。**
- 编号卡片：首页播放卡、我的音乐库；工具默认折叠，续播提示独立显示。
- 深浅主题、播放底栏、管理弹窗、黑胶页和桌面图标统一配色。
- 未自定义名称时默认“拾音”；已有名称不变。

## 功能保留

滚动歌词及时间偏移、收藏和歌单导入导出、MP3/FLAC/M4A 标签及内嵌封面识别、睡眠定时、桌面应用、断点续播与最近播放、批量管理及排序、播放页外观及专辑独立背景。

不播放或暂停时隐藏底栏；点封面进入黑胶页，唱片跟随播放状态转动。

## 数据与限制

- 收藏、歌单、历史和播放进度保存在当前设备/浏览器。换设备前可导出歌单，清理网站数据会丢失本机记录。
- 原有R2歌曲、歌词、站点设置和外观继续存在R2；TG歌曲的自定义信息、海报和歌词存在D1。
- 离线只提供提示页，不缓存音乐或管理凭据。
- iOS 后台播放、定时和音量渐弱受系统限制，不保证在网页被冻结后准时执行。
- 批量删除不可撤销，多个 R2 对象的操作不是事务；部分失败会报告。

## 校验

执行 `npm test` 和 `npm run test:browser` 验证两种主题的TG音频导入、D1元数据/海报编辑、R2数据保留和音频播放。
